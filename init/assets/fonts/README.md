# Interface fonts

The approved "Living Chancellery" interface uses Golos Text for controls and
body text and Roboto Slab at weight 500 for headings. Both include Cyrillic.
Fonts are bundled so the game does not need network access.

- Golos Text: https://github.com/google/fonts/tree/main/ofl/golostext
  License: SIL Open Font License 1.1, included in `golos_text-OFL.txt`.
- Roboto Slab: https://github.com/google/fonts/tree/main/apache/robotoslab
  License: Apache License 2.0, included in `roboto_slab-LICENSE.txt`.
