# Character sheets

One sheet per character: role and scenes, a pointer to the look, voice with sample lines, wants, secrets, how the bond grows. The look is defined once, in `art/PROMPTS.md` ("Established looks" for approved portraits, numbered entries for proposals), so there is a single source for appearance. Voice and secrets live here, and `docs/story/GUIDE.md` keeps the short table.
